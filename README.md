## 🎯 Objetivo General

Identificar y aplicar la estructura básica del Frontend mediante **HTML5**, organizando correctamente los elementos de una página web personal a través de etiquetas semánticas, jerarquía de encabezados, listas, imágenes y enlaces hipertexto.

---

## 📚 Contenidos Desarrollados

1. **Estructura básica del documento HTML:** Declaración `<!DOCTYPE html>`, etiquetas raíz `<html>`, cabecera `<head>` y cuerpo visible `<body>`.
2. **Jerarquía de encabezados:** Uso estructurado y semántico de niveles desde `<h1>` hasta `<h6>`.
3. **Párrafos de texto:** Empleo de etiquetas `<p>`, `<strong>` y `<em>` para presentación personal y descripciones.
4. **Listas desordenadas:** Organización de elementos temáticos con `<ul>` y `<li>`.
5. **Contenido multimedia y enlaces:** Inserción de imágenes con `<img>` y enlaces externos con `<a>` configurados de manera segura (`target="_blank"` y `rel="noopener noreferrer"`).
6. **Diseño y estilos:** Integración de `styles.css` con diseño responsivo, Flexbox y Grid.
